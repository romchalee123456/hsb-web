# HSB-Web (Hungsangbaan Web)

## Overview

HSB-Web (Hungsangbaan Web) is a web application designed to track and manage on-site work activities of technicians. The system consists of:

- **Frontend Web**: A responsive web application.
- **PWA-Web**: A Progressive Web App for mobile-friendly access.
- **Backend API**: A Node.js-based API server for handling data and business logic.

## Tech Stack

### Frontend

- **Vue.js**: Frontend framework for building the web application.
- **PrimeVue**: UI component library for Vue.js.

### Backend

- **Node.js**: JavaScript runtime environment.
- **Express.js**: Web framework for building RESTful APIs.
- **Prisma ORM**: Database ORM for managing database interactions.

## Installation

### Prerequisites

- [Node.js](https://nodejs.org/)
- [Vue.js](https://vuejs.org/)
- [Prisma ORM](https://www.prisma.io/)
